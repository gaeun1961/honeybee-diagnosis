# 파일명 첫 글자(촬영 장소)별 test AP

`python src/evaluate.py --by-site`로 생성. 가중치 `best.pt` (입력 512px), 기본 분할 test 200장.
양성이 5장 미만인 클래스는 "표본 부족", 전부 양성이면 "음성 없음"으로 AP를 내지 않음. 평균 AP는 AP를 낸 클래스만 평균.

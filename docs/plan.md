# Plan — 꿀벌 유충 질병 진단

## 한 줄 목표
꿀벌 유충 사진 1장으로 응애·석고병·부저병 확률과 병변 위치(Grad-CAM)를 보여 주는 로컬 웹 데모. 개인 포트폴리오, 진단 도구가 아닌 참고용.

## 기술 스택·구조
- 데이터: AI Hub 71667 Validation(VS.zip 사진, VL.zip 라벨). zip은 풀지 않고 zipfile로 읽음. 라벨은 JSON `category_id` 기준(폴더명 석고병·부저병 뒤바뀜).
- 모델: ImageNet 사전학습 ResNet18 다중 라벨(BCEWithLogits), CPU 학습, 서비스는 512px.
- 처리 흐름: `make_subset.py` → `split.py`(50장 블록) → `train.py` → `evaluate.py` → `serve.py`(FastAPI) ← `web/index.html`(오프닝 + 서비스 미리보기)
- 보조 분석: `sweep.py`, `prefix_check.py`, `env_stats.py`, `evaluate.py --by-site`

## MVP 범위
| 포함 | 제외 |

| R-08 | Grad-CAM이 병변을 보는지 검증 | 완료 (docs/cam_check.md) |

## 예외 상황
- 유충이 아닌 사진·관계없는 사진: 모델은 항상 확률을 냄 → 결과 패널에 "유충 사진 전용, 참고용, 다른 장소 성능 미확인" 안내를 항상 표시 (입력 사진 판별은 하지 않음)
- 이미지 형식 오류·너무 큰 파일: API가 400과 메시지 반환
- 서버가 꺼져 있음: 웹에서 "로컬 서버를 켜세요" 안내
- 한 사진에 병 여러 개(석고병·부저병 동시 다수): 다중 라벨로 각각 표시
- B 접두어(석고병·부저병)·C 접두어(응애·정상) 편향: 다른 장소 사진 성능은 미확인으로 명시

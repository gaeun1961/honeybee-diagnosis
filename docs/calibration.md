# 확률 보정 (temperature scaling)

`python src/calibrate.py`로 생성. 가중치 `best.pt` (입력 512px), val 200장으로 T 맞춤, test 200장은 측정만.
보정 확률 = sigmoid(logit / T). 0.5 판정·AP는 그대로이고 확률 값만 바뀜 (최고 클래스는 공통 T일 때만 그대로).
주의: 응애 클래스별 T가 탐색 범위 끝(0.1)에 걸림 (val에서 거의 완전히 분리돼 BCE가 T를 끝까지 밀어냄).
ECE: 클래스별, 등간격 10구간. 서버용으로 test ECE 평균이 낮은 **공통 T** 를 `models/temperature.json`에 저장.
한계: val은 체크포인트 선택·임계값 조정에도 쓰였으므로 val ECE는 낙관적일 수 있음. 또 방식(공통/클래스별) 선택에 test ECE를 썼으므로 선택한 쪽의 test ECE도 낙관적일 수 있음. 각 200장이라 ECE 차이 0.01 수준은 개선으로 단정하기 어려움.
